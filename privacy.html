Privacy policy

Last updated: 2026-11-02.

paulinus-rclone is a personal backup tool used only by its owner. It uploads the owner's own files to the owner's own Google Drive and downloads them back.

What data it accesses

It requests only the drive.file scope, so it can see only the files it has created itself. It does not read any other file, email, contact or profile data in the Google account.

What it does with the data

The files stay on the owner's computer and in the owner's Google Drive. The tool does not send them, or any information about them, anywhere else. Nothing is collected, sold or shared with third parties, and nothing is used for advertising.

The OAuth token is stored only on the owner's computer, in rclone's local configuration file.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be revoked at any time at myaccount.google.com/permissions.
