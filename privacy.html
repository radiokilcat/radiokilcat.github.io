paulinus-rclone privacy policy

Last updated: 2026-11-02.

This privacy policy describes how paulinus-rclone ("the app") accesses, uses, stores and shares Google user data. The app is a personal backup tool built on rclone. It is developed and used by one person, the owner of this site, to copy their own data files to their own Google Drive and to download them back. It is not offered to the public.

1. Google user data the app accesses

The app requests one OAuth scope: https://www.googleapis.com/auth/drive.file. With this scope the app can:

  • create files and folders in the user's Google Drive;
  • read, update and delete only the files and folders that the app itself created;
  • read the Drive storage quota (total, used and free space).

The app cannot see any other file in Google Drive. It does not access Gmail, Contacts, Calendar, Photos, or the user's name, email address or profile.

2. How the app uses that data

The data is used only to provide the backup function the user asked for: to upload backup files, to list and download them, to delete old backups, and to check that there is enough free space. The data is not used for any other purpose. It is not used for advertising, it is not sold, and it is not used to train any machine learning or AI model.

3. Data collection

The app does not collect data. It has no server, no analytics, no telemetry and no cookies. All processing happens on the user's own computer, and the files go directly from that computer to Google Drive over an encrypted HTTPS connection.

4. Storage and security

The OAuth access token and refresh token are stored only on the user's own computer, in rclone's local configuration file. They are never sent anywhere except to Google's own servers to authorize requests. The backup files are stored in the user's own Google Drive, under the user's Google account and Google's own security controls.

5. Sharing

The app does not share, transfer or disclose Google user data to any third party. No person other than the user has access to it.

6. Retention and deletion

Backup files stay in the user's Google Drive until the user deletes them, either with the app or in Google Drive itself. The tokens stay on the user's computer until the user deletes the rclone configuration or revokes access. Access can be revoked at any time at myaccount.google.com/permissions. After revocation the app can no longer reach the user's Drive.

7. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to this policy

If this policy changes, the new version will be published on this page with a new "Last updated" date.

9. Contact

Questions about this policy can be sent through github.com/radiokilcat.
